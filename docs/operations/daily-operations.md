# 日常オペレーション

## 新規案件の作成

1. https://conduit-app.com/admin にログイン
2. 「＋ 新規」ボタンをタップ
3. 以下を入力：
   - クライアント名
   - 投稿予定日時
   - キャプション・ハッシュタグ
   - Instagram設定（Account ID・アクセストークン）
   - 写真をアップロード（メイン最大6枚・サブ最大6枚）
4. 「案件を作成する」で保存 → ステータスが「確認待ち」になる

## 確認URLの送付

プロジェクト詳細ページに確認URLが表示される：  
`https://conduit-app.com/confirm/{token}`

このURLをLINEやメールでクライアントに送付する。

## フィードバック受信後の対応

1. LINEに「フィードバック受信」通知が届く
2. 管理画面でフィードバック内容を確認（フィードバック詳細ページ）

### 全OK の場合
- 自動的に投稿予約される（ステータス: 投稿予約中）
- 予定日時になるとCloud Functionsが自動投稿

### NGあり の場合
1. フィードバック詳細ページで「修正対応を開始する」をタップ
2. NG写真を差し替え（プロジェクト詳細ページの修正パネル）
3. 「再確認を依頼する」で新しい確認URLを発行
4. クライアントに新URLを送付

## 投稿予約のキャンセル・変更

プロジェクト詳細ページ → 予約取消ボタン → 新しい日時を設定して再予約

## ステータス一覧

| ステータス | 表示 | 意味 |
|-----------|------|------|
| 下書き | 青 | 未送付 |
| 確認待ち | 黄 | クライアントが確認中 |
| FB受信 | 赤 | フィードバックあり・対応必要 |
| 修正対応中 | 青 | 写真差し替え作業中 |
| 投稿予約中 | 緑 | 全承認・自動投稿待ち |
| 投稿完了 | 緑 | 完了 |
| エラー | 赤 | 投稿失敗・要対応 |
