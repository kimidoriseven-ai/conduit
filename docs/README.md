# Conduit ドキュメント

Instagram投稿確認アプリ「Conduit」の技術ドキュメント・運用マニュアル集です。

## このドキュメントについて

| 対象 | 内容 |
|------|------|
| 開発者 | アーキテクチャ・設定手順・データモデル |
| 運用者（担当者） | 日常操作・トークン管理・トラブル対応 |
| クライアント | 写真確認の操作マニュアル |

## 本番環境

- **URL**: https://conduit-app.com
- **管理画面**: https://conduit-app.com/admin
- **Firebaseプロジェクト**: `instagram-post-confirm`
